# 요구사항 정의서 (Requirements Specification)

> 본 데모의 테스트 대상에 대한 요구사항을 정의합니다. 공개 샌드박스(saucedemo.com / reqres.in)와 목킹 환경의 동작을 기준으로, "요구사항 정의 → 테스트 설계 → 추적성 확보" 흐름을 시연하기 위한 문서입니다.
> 각 요구사항은 [테스트 케이스 명세](test-cases.md) 및 [요구사항 추적 매트릭스](traceability-matrix.md)와 연결됩니다.
> 티맵 성격 기능(경로검색·즐겨찾기·장소추천)은 실제 티맵 API가 아니라 **목킹(가상 응답)** 기준의 데모 요구사항입니다.

## 요약

| 항목 | 값 |
| --- | --- |

| 기능 요구사항 | 13 |

| 우선순위 척도 | P1(High) · P2(Medium) · P3(Low) |
| 기준 | ISO/IEC 25010 |

## 기능 요구사항

| 요구사항 ID | 분류 | 요구사항 설명 | 인수 기준 (Acceptance Criteria) | 우선순위 | 품질 특성 |
| --- | --- | --- | --- | --- | --- |
| REQ-AUTH-01 | 인증 > 로그인 | 유효한 계정으로 로그인하면 상품 목록으로 이동해야 한다 | 정상 계정 입력 시 inventory 화면 진입, 목록 노출 | P1 | 기능적합성 |
| REQ-AUTH-02 | 인증 > 로그인 | 잠긴 계정은 로그인이 차단되고 사유가 안내되어야 한다 | 잠긴 계정 입력 시 'locked out' 오류 노출 | P1 | 보안 |
| REQ-AUTH-03 | 인증 > 로그인 | 필수 입력값 누락 시 적절한 오류를 안내해야 한다 | 비밀번호 미입력 시 'Password is required' 노출 | P2 | 기능적합성 |
| REQ-CART-01 | 상품 > 장바구니 | 상품을 장바구니에 담으면 수량이 정확히 반영되어야 한다 | 담기 후 장바구니 배지 카운트 1 증가 | P2 | 기능적합성 |
| REQ-API-01 | API > 사용자 > 조회 | 단일 사용자 조회 시 200과 규격 응답을 반환해야 한다 | 200, data.id/email/이름 필드 정합 | P1 | 기능적합성 |
| REQ-API-02 | API > 사용자 > 조회 | 존재하지 않는 사용자 조회 시 404로 처리해야 한다 | 미존재 ID 조회 시 404 반환 | P2 | 신뢰성 |
| REQ-API-03 | API > 사용자 > 생성 | 사용자 생성 요청 시 201과 생성 데이터를 반환해야 한다 | 201, 요청 값 반영 + id/createdAt 존재 | P1 | 기능적합성 |
| REQ-API-04 | API > 사용자 > 목록 | 사용자 목록 조회 시 페이징 메타 정보를 정확히 반환해야 한다 | 200, data 배열 + page/per_page/total 정합 | P2 | 기능적합성 |
| REQ-ROUTE-01 | 경로검색 > 조회 | 경로 검색 정상 응답 시 경로 데이터가 규칙에 맞아야 한다 | routes 정합, 최단경로 소요시간 < 대안경로 | P1 | 기능적합성 |
| REQ-ROUTE-03 | 경로검색 > 조회 | 경로 검색 결과가 없을 때 빈 목록을 정상 처리해야 한다 | routes 빈 배열([]) 반환 시 배열 타입 유지(오류 아님) | P3 | 사용성 |
| REQ-FAV-01 | 경로검색 > 즐겨찾기 | 즐겨찾기 목록 조회 시 규격에 맞는 항목을 반환해야 한다 | 각 항목에 name/lat/lng 필드 존재 | P2 | 기능적합성 |
| REQ-FAV-02 | 경로검색 > 즐겨찾기 | 즐겨찾기 추가 시 201과 생성 결과를 반환해야 한다 | 201, 요청(name/좌표) 반영 + id 발급 | P2 | 기능적합성 |
| REQ-PLACE-01 | 장소추천 > 로컬맛집 | 장소 추천 목록은 평점 내림차순으로 정렬되어야 한다 | places가 rating 내림차순 정합 | P2 | 기능적합성 |

| --- | --- | --- | --- | --- | --- |

| REQ-COMPAT-01 | 공통 > 호환성 | 주요 UI 시나리오는 데스크톱·모바일 뷰포트에서 동일 동작해야 한다 | Desktop Chrome·Pixel 7 두 프로젝트 통과 | P2 | 호환성 |

## 비고

- 공개 샌드박스/목킹 환경 기준의 데모 요구사항이며, 실제 서비스/회사 요구사항이 아닙니다.
- 경로검색·즐겨찾기·장소추천은 page.route 목킹으로 구현한 **가상 시나리오**입니다(실제 티맵 API 호출 아님).
- 우선순위(P1~P3)는 발생 가능성과 영향도를 고려한 Risk-Based Testing 기준으로 부여했습니다.
